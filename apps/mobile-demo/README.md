# چارخونه: نسخهٔ نمایشی کم‌حجم اندروید

این بسته فقط پیش‌نمایش وب تأییدشده را در Android WebView نشان می‌دهد. اتصال اینترنت لازم است؛ تغییرات رابط در Render منتشر می‌شوند. این بسته جایگزین برنامهٔ کامل React Native، ورود واقعی، API، اعلان‌های فوری یا عملکرد آفلاین نیست.

آدرس نمایش: `https://charkhoone-mobile-preview.onrender.com/preview/home`

بستهٔ نمایشی شناسهٔ `ir.charkhoone.demo` دارد و کنار برنامهٔ اصلی `ir.charkhoone.app` نصب می‌شود. خروجی GitHub Actions با کلید Debug موقت امضا می‌شود و صرفاً برای ارائه است.
